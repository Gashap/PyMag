# ДЗ 3 — трекер книг и свой баг
## Почему выбраны именно эти коллекции
**list** (`_books`) хранит все записи в порядке добавления: этот набор постоянно меняется, а порядок нужен для вывода.
**tuple** (`Book` — это `NamedTuple`) описывает одну книгу: у записи фиксированный набор полей, которые не должны меняться, а неизменяемость защищает от случайных правок — поэтому жанры внутри записи хранятся во `frozenset`, а не в `set`.
**dict** (`_by_id`, `_by_key`) даёт поиск за O(1) по id и по паре «название + автор» для защиты от дублей, причём ключом служит кортеж, а не список.
**set** (`_authors`, `genres()`) используется там, где важна только уникальность: у двух книг Достоевского автор хранится один раз.
Наружу методы отдают копии, сортируют через `sorted()`, удаляют через новый список, а аргумент по умолчанию — пустой кортеж, поэтому ловушек с алиасами, мутацией при итерации и mutable default нет.
